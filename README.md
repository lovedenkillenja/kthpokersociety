# KTH Poker Society

Website and play-money poker game for KTH Poker Society (a student association at KTH Royal Institute of Technology).

- Start here: `AGENTS.md` (rules for agents) and `docs/PROJECT.md` (overview, infrastructure map, current state, open issues).
- Databases and where to find data: `docs/DATABASE.md`. Schema snapshots: `supabase/schema/`.
- Live site: https://kthpokersociety.se (branch `v3-merged-design`, deployed by Netlify on every push).
- Static site, no build step: `index.html` is the whole website; the game lives in `game/`.
